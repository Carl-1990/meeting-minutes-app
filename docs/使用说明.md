# 会议纪要 使用说明

完全离线的 macOS 会议记录：电脑麦克风 → 实时中文（可中英混说）逐字稿 → 发言人标签 → 结束时在桌面生成 Word 和录音。

## 安装后第一次打开

安装包是 ad-hoc 签名，没有公证。请先看磁盘映像里的「首次打开说明」：在「应用程序」里对「会议纪要」**右键 → 打开 → 打开**。若系统说已损坏，在终端执行：

```bash
xattr -cr /Applications/会议纪要.app
```

## 开会

1. 点击「开始会议」。系统第一次会询问麦克风权限，请允许。按钮在收到真实、非全零的麦克风数据后变成绿色，文字变为「会议进行中」。若保持灰色，请到「系统设置 → 隐私与安全性 → 麦克风」里打开本应用。
2. 右侧会实时出现灰色斜体的未定稿文字；一句话结束后定稿，并带上 `[HH:MM:SS]` 和发言人。
3. 「暂停会议」后按钮变为「继续会议」，开始按钮变为黄色。暂停期间的声音不转写，也不写入录音。
4. 「结束会议」会先确认，然后把 `会议纪要_YYYYMMDD_HHMM.docx` 和同名录音（优先 `.m4a`，否则 `.wav`）保存到桌面。

## 发言人

- 默认「自动识别发言人」。一句话够长（约 1 秒以上）才会提取声纹；太短则沿用上一位。和已有声纹的相似度达到阈值（默认 0.55，可在「设置」里改）就归为该人，否则新建下一位，最多 10 位。
- 「手动选择发言人」时，单击发言人按钮指定之后每句话的归属。
- 自动模式下单击某个发言人，只强制**下一句**归为该人。
- 双击发言人按钮可以改名。右侧已经出现的该发言人句子，以及导出的 Word，都会换成新名字。
- 在某一句上右键 →「改为发言人」，会改正这一句，并把这句的声纹并入那一位，后面的自动识别会更准。

## 自动保存

每一句定稿都会写入 `~/Library/Application Support/MeetingMinutes/sessions/`。如果软件中途退出，下次打开会询问是否恢复或导出。

## 局限

单个笔记本麦克风、几个人同时说话、或声音很接近时，自动区分发言人的准确率会下降。安静的会议室、轮流发言、使用全向会议麦克风时效果更好。目标是在这种条件下 2～4 人轮流发言的归属正确率不低于 85%，但这取决于麦克风和房间，安装包本身无法在打包机上替你验证。
